EMNLP 2026 Findings 제2저자

VocMoE: Vocabulary-Guided Mixture-of-Experts for Korean Medical Language Models

Sangyeon Cho, Jaeho Han, Mingyu Jeon, Junyeong Kim

한국어 의료 언어 모델의 성능 저하 원인을 의료 용어의 과도한 토큰 분절과 학습 과정의 표현 정렬 문제로 분석했습니다. 의료 어휘 확장과 어휘 기반 전문가 라우팅을 결합한 VocMoE를 제안하여, 논문 실험에서 도메인 용어당 평균 토큰 수를 4.5개에서 1.6개로 줄이고 한국어 의료 및 일반 벤치마크 성능을 함께 개선했습니다.

  • BM25·임베딩 기반 하이브리드 검색, 재정렬 모델, 검색 근거를 활용하는 생성 모델 학습 및 비교 평가
  • 답변과 원문 출처 확인, 근거 부족 시 답변 보류 기능을 포함한 웹 데모·API 구현

편향 완화를 위한 이력서–채용공고 매칭 모델

2025.09 – 현재 · 2026.12까지 참여 예정

이력서와 채용공고의 매칭을 예측하고, 민감속성 변화에 따른 예측 변동을 줄이는 모델을 개발했습니다. 데이터 전처리·모델 학습·평가 전반을 담당했으며, 특히 편향 완화 방법의 설계와 구현에 집중했습니다.

  • 채용 데이터 전처리 및 양성·음성 쌍 525,448건으로 학습·평가 데이터 구성
  • 한국어 임베딩 모델 KURE와 MLP 기반 이력서–채용공고 매칭 예측 모델 구현
  • 주요 예측 정보를 보존하면서 분류기를 수정하는 Null-space 기반 편향 완화 방법 적용
  • 실험용 성별 속성 변경 전후의 예측 안정성을 평가하여 매칭 정확도와 공정성을 함께 검증
매칭 정확도 92.5% · 개인공정성 지표 99.5% 과제 발표자료의 실증 결과 기준. 공정성은 실제 성별 대신 부여한 실험용 속성의 변화에 대한 예측 안정성으로 평가.
